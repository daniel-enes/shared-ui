Overview

shared-ui is an accessible component library for Angular 22, built with Signals, Signal Forms, and standalone components. It follows WCAG 2.2 AA guidelines and provides form components, buttons, alerts, and more.

When to use

  • You need accessible UI components for Angular 22 applications.
  • You want a lightweight library based on Bootstrap CSS (without Bootstrap JavaScript).
  • You prefer Signals and modern Angular APIs.
