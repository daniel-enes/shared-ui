Installation

Install shared-ui via npm and start using the components.

Install via npm

npm install shared-ui

Peer dependencies

shared-ui requires Angular 22. Make sure the following peer dependencies are installed:

  • @angular/common ^22.3.0
  • @angular/core ^22.3.0

Bootstrap CSS

shared-ui uses Bootstrap 5 CSS as its visual base. Add Bootstrap CSS to your application styles:

  • node_modules/bootstrap/dist/css/bootstrap.min.css
  • node_modules/bootstrap-icons/font/bootstrap-icons.css
  • src/styles.scss

Bootstrap JavaScript is not required and should not be added.
