WCAG 2.2 AA

All shared-ui components are designed to meet WCAG 2.2 Level AA criteria, including:

  • Keyboard navigation
  • Visible focus indicators
  • Sufficient color contrast
  • ARIA attributes and landmarks
  • Reduced motion support

ARIA attributes

Each component exposes the appropriate ARIA attributes for its role. Refer to the individual component pages for details.
