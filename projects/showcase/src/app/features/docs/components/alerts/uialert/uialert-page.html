Demonstration

Success

Your changes have been saved successfully.

Information

Please review the updated terms of service.

Warning

Your session will expire in 5 minutes.

Error

An unexpected error occurred. Please try again.

Code example

<ui-alert
  [title]=""Success""
  [message]=""Your changes have been saved successfully.""
  [variant]=""success""
  [visible]="true"
  [dismissible]="true"
  (dismissed)="onDismissed()">
</ui-alert>

Inputs

Property Type Default Description
title string '' Alert title.
message string '' Alert message.
variant 'success' | 'info' | 'warning' | 'danger' 'success' Visual variant of the alert.
visible boolean false Whether the alert is visible.
dismissible boolean false Whether the alert can be dismissed.

Outputs

Event Description
dismissed Emitted when the alert is dismissed.

Accessibility

  • Receives programmatic focus when it appears.
  • Uses role="alert" for screen readers.
  • Dismiss button is keyboard accessible.
