Code example

<ui-form-input
  [field]="form.username"
  label="Username"
  placeholder="Enter your username"
  description="Use at least 8 characters."
  fieldName="username">
</ui-form-input>

Inputs

Property Type Default Description
field FieldTree<string> Required Signal form field.
label string '' Field label.
description string '' Field description text.
descriptionItems readonly string[] [] List of description items.
placeholder string '' Input placeholder.

Accessibility

  • Associated <label> via for attribute.
  • Description linked via aria-describedby.
  • Error state uses aria-invalid="true".
