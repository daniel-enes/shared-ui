FormTextarea

Multi-line text input field.

When to use

Use for longer text input.

Demonstration

Code example

<ui-form-textarea
  [field]="form.description"
  label="Description"
  placeholder="Enter details..."
  fieldName="description">
</ui-form-textarea>

Inputs

Property Type Default Description
field FieldTree<string> Required Signal form field.
label string '' Field label.
description string '' Field description text.
rows number 4 Number of text rows.

Accessibility

  • Associated <label> via for attribute.
  • Description linked via aria-describedby.
