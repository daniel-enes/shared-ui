UiButtonLink

Button styled as a link.

When to use

Use for secondary actions or navigation.

Demonstration

Button link

Code example

<ui-button-link [routerLink]=""/en/docs/getting-started/introduction"">
  Go to introduction
</ui-button-link>

Inputs

Property Type Default Description
routerLink any undefined Router link target.
target string '_self' Link target.

Accessibility

  • Rendered as an <a> element.
  • Keyboard navigable.
  • Visible focus indicator.
