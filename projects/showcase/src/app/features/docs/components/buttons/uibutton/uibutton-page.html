UiButton

Primary action button component.

When to use

Use for main actions in forms and dialogs.

Demonstration

Code example

<ui-button variant="primary" (click)="onClick()">
  Click me
</ui-button>

Inputs

Property Type Default Description
variant 'primary' | 'secondary' | 'outline' | 'danger' 'primary' Visual variant of the button.
size 'sm' | 'md' | 'lg' 'md' Button size.
disabled boolean false Whether the button is disabled.

Outputs

Event Description
click Emitted when the button is clicked.

Accessibility

  • Keyboard activatable (Enter, Space).
  • Visible focus indicator.
  • Disabled state communicated via aria-disabled.
